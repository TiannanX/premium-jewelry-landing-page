# Premium Jewelry Landing Page

A responsive premium jewelry landing page demo exported from Figma Make and prepared as a standalone Vite + React project.

The page design, copy, layout, and imagery are kept from the original Figma Make export. This repository is intended for portfolio/demo deployment on GitHub, Vercel, or Netlify.

## Tech Stack

- Vite
- React
- Tailwind CSS
- Figma Make exported source

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will print a local URL, usually:

```bash
http://localhost:5173/
```

## Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The production output is generated in:

```bash
dist/
```

## Deploy To Vercel

Use these settings:

- Framework Preset: `Vite`
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`

If this project lives inside a larger repository, set Vercel's Root Directory to:

```bash
premium-jewelry-landing-page
```

## Deploy To Netlify

Use these settings:

- Build Command: `npm run build`
- Publish Directory: `dist`

If this project lives inside a larger repository, set the Base Directory to:

```bash
premium-jewelry-landing-page
```
